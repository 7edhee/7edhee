## Identity

I’m a hobbyist developer who likes turning small ideas into working software. My projects move between browser extensions, interactive web experiences, Android interfaces, portfolio sites, music tools, and algorithm practice.

I prefer compact, independent projects that are easy to run, inspect, and improve.
